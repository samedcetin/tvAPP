# ux
## SUMMARY
As of Oct 2026 the official path for TV UI is Jetpack Compose for TV. Leanback is officially deprecated. The tv-material 1.1.0 and tv-foundation 1.0.0 artifacts both went stable on 2026-05-06. The Compose for TV docs (updated 2026-10-16) use Compose BOM 2026.09.00 and say to replace mobile material3 with tv-material, not use both. tv-foundation's lazy layouts were removed in Jan 2025, so use the standard Compose foundation LazyRow/LazyColumn/LazyVerticalGrid. tv-material provides Surface, Card variants, Carousel, NavigationDrawer/ModalNavigationDrawer, TabRow/Tab, Assist/Filter/Input/Suggestion chips, ListItem/DenseListItem, Button/WideButton/IconButton, Switch/RadioButton/Checkbox. Each focusable component exposes Scale/Border/Glow/Colors/Shape for focus states.

Official 10-foot rules:
- Design at 960x540 dp (1 dp = 1 px at MDPI, assets aimed at 1080p).
- Safe margins of about 5%: 58 dp sides and 28 dp top/bottom, though the same page also says 48/27 dp.
- 12-column grid with 52 dp columns and 20 dp gutters. Cards: 4 per row = 196 dp, 3 = 268 dp, 6 ≈ 124 dp.
- Focus scale defaults are 1.025, 1.05 and 1.1. Glow is 2–32 dp.
- Everything must be reachable with the D-pad, with one focused item at a time.
- Back always goes to the previous screen and finally to the Google TV home.
- No exit gating or confirmation, no on-screen back button, and the splash screen is not in the back stack.

The TV app quality page (updated 2026-06-29) requires:
- LEANBACK_LAUNCHER, a 320x180 banner containing the app name, and an icon of at least 160x160.
- Touchscreen not required, landscape, no overscan clipping, and an opaque full-screen UI.
- Full 5-way D-pad navigation and no dependence on a Menu button.
- minSdk 31 or lower.
- Video pauses when the user leaves the app, and Ambient Mode is blocked during playback.
- From Aug 1, 2026, 64-bit plus 16 KB pages (this applies to Play).

The May 2026 Tier 1 adds an enhanced accessibility item covering high-contrast mode and simplified navigation, which fits this family's needs. Accessibility evidence (Ofcom, TetraLogical, Amazon's 28 px at 1080p floor) points to the same rules:
- Large, user-adjustable text and focus shown by more than color alone (border plus scale).
- No auto-hiding of important information and as few key presses as possible.
- Older users find channel-number zapping easiest and mostly watch 4–7 channels, which makes favorites and up/down zapping key.

A 2026 analysis of Pluto TV reviews shows heavy complaints after up/down channel surfing was removed. Keep up/down zapping in the fullscreen player.

The recommended shape is:
1. A Home screen with a resume card, a filter-chip row and a 4–5 column channel-logo grid.
2. A fullscreen player with ▲▼ zapping, an info banner and an OK/◀ channel-list side panel.
3. An options dialog for favorites, loading/error/no-internet states, and a simple Settings screen with large-text mode.
4. Later: EPG, search, sleep timer, PIN lock, self-update.

Design in Figma with Google's TV Design Kit (goo.gle/tv-design-kit) at 960x540 frames. Google's Relay Figma-to-Compose tool appears to have been sunset (2025), so hand-off is manual (Figma Dev Mode, Material Theme Builder tokens, optionally the Figma MCP server feeding Claude Code with Code Connect).

## RECOMMENDATIONS
- Tech stack: Kotlin + Jetpack Compose (BOM 2026.09.00) with androidx.tv:tv-material:1.1.0. Add tv-foundation:1.0.0 only if needed. Use androidx.compose.foundation LazyVerticalGrid/LazyRow/LazyColumn and Media3 1.11.x ExoPlayer with HLS and a Compose player surface. Do NOT use Leanback or mobile material3 alongside tv-material. minSdk ≤ 31 (e.g., 26–28), latest targetSdk, landscape, android.hardware.touchscreen required=false, android.software.leanback required=false, LEANBACK_LAUNCHER intent, 320x180 banner with the app name, 160x160+ icon. Ship a universal or arm64-v8a + armeabi-v7a APK for sideloading.
- Layout system: Figma frames 960x540 (1 px = 1 dp). Safe area 58 dp left/right and 28 dp top/bottom; never put text or focusable items outside it. 12-column grid, 52 dp columns, 20 dp gutters. Channel grid: 5 columns (≈152 dp cards) at normal text size, 4 columns (196 dp) in Large mode, 3 columns (268 dp) in Extra-large. Channel cards 16:9 with the logo centered on a neutral or brand surface. The channel name and number always sit below the card as text, not only on focus.
- Type scale for elderly users (dp/sp at the 960x540 canvas; ×2 = px at 1080p): never below 14 sp (28 px, the Amazon floor). Defaults: card channel name 16–18 sp, chip labels 16–18 sp, body/now-next 16 sp, info-banner channel name 28–32 sp, screen titles 28–32 sp. Provide Yazı boyutu: Normal 1.0x / Büyük 1.25x / Çok büyük 1.5x via a custom Typography multiplier, and also respect system fontScale. Use Roboto or a highly legible sans (e.g., Inter, Noto Sans) and test Turkish glyphs (ç, ğ, ı, İ, ö, ş, ü).
- Colors: dark theme only (surface ~#121318, near-black but not pure #000 for UI; pure black only for video letterbox). Aim for at least 7:1 contrast for body text and 4.5:1 minimum for secondary text, verified on the actual TV. Avoid large pure-white areas.
- Focus style, one uniform scheme app-wide that never relies on color alone: focused = scale 1.05 (grid cards, list rows) to 1.1 (buttons, chips), plus a 3 dp high-contrast border (white or amber #FFC107 on dark), plus a lighter surface. Optional subtle glow. Keep animations short (~150 ms). Unfocused = no border. A selected chip has a filled background and a check icon, so selected and focused stay distinguishable.
- Navigation map (max depth 2): Home (start destination) → Player. Home → Ayarlar. Everything else is an overlay or dialog. Use focusRestorer on the grid and chip row, so returning from the Player focuses the card of the channel that was playing. Give initial focus to the 'Kaldığın yerden' resume card, or the last channel card. Back = close the topmost layer. In Home, Back from the grid scrolls to top and focuses the selected chip; Back again exits the app with no dialog, per Google guidance.
- Startup: Home stays the start destination. If 'Açılışta son kanalı başlat' is on (default ON for this family), the Player is pushed automatically with the last channel and Home sits underneath, so Back from the Player lands on Home. Use the Android 12 SplashScreen API and keep the splash out of the back stack.
- Player remote map: ▲/▼ (and CH+/CH− if present) = previous/next channel within the active filter, wrapping around, with a Settings option to invert. OK or ◀ = channel list side panel. ▶ = info banner with now/next. Back = close overlay, else go to Home. Play/Pause key = pause/resume. Digits (if received via CEC) = direct tune after a 2 s timeout. No D-pad key may be 'silent'; every press gives visible feedback. Show the info banner on every zap and auto-hide it after 5 s (configurable 3/5/10 s). Pause or stop playback in onStop (TV-NP) and keep the screen on during playback (TV-BU).
- No hidden gestures: long-press OK may be a shortcut to Kanal seçenekleri, but every action must also be reachable visibly. Use ▶ on a channel-list row (with a visible '›' hint) or a 'Favorileri düzenle' button in the Home header that enters a mode where OK toggles ★. Show key hints in the banner and panel footer in plain Turkish ('▲▼ Kanal değiştir · OK Kanal listesi · Geri Ana ekran').
- Filtering: a single-select FilterChip row on Home and repeated at the top of the in-player channel list. Chips: ★ Favoriler, Tümü, Genel, Haber, Spor, Çocuk, Belgesel, Müzik, plus Ekonomi or Diğer only if needed. Apply the filter when a chip is focused (debounced ~300 ms, the TV tab convention) and test with the parents against apply-on-OK. Remember the last selected chip. Up/down zapping follows the active filter, so 'Favoriler' becomes the parents' personal channel ring.
- States: (1) Loading: logo + name + spinner + 'Yayın açılıyor…' while ▲▼ still works. Retry silently with a backup URL. After ~10 s, show (2) the error overlay 'X şu anda açılamıyor' with buttons Tekrar dene (focused) / Sonraki kanal / Ana ekran. (3) No internet: full-screen message with Tekrar dene and auto-recovery through a ConnectivityManager callback. (4) Empty favorites or empty filter: explanation plus a 'Tüm kanallara git' button. Never leave the user on a black screen with no focusable element.
- Wording: simple Turkish, short verbs, no jargon (no EPG, stream, buffer, IPTV, cache). Examples: 'Kanallar', 'Favoriler', 'Tümü', 'Ayarlar', 'Tekrar dene', 'Yayın açılamadı', 'Şimdi', 'Sonra'. Keep one action per button and confirm only destructive actions, such as resetting favorites, with an explicit Vazgeç (Cancel).
- Performance on 2 GB RAM: no autoplaying video previews in the grid. Use small, size-constrained logos (Coil with memory and disk limits; logos bundled or pre-sized to ~2x card size). Enable R8 and add Baseline Profiles (TV-BP). Release the player on stop and reuse a single ExoPlayer instance when zapping.
- Figma workflow: duplicate Google's TV Design Kit (goo.gle/tv-design-kit) and build at 960x540 frames. Define tokens (color roles from Material Theme Builder, a type scale with Large/XL variants, spacing 4/8/12/20/28/58, shapes with 12–16 dp corners) as Figma variables. Design every focus state (default, focused, selected, disabled) for each component plus all overlays and states. Export logos and icons as SVG or vector drawables. Hand off via Dev Mode, plus the Figma MCP server if Claude Code builds it, ideally with Code Connect mapped to the app's Compose components. Relay is no longer an option.
- Verification: test on the Android TV/Google TV 1080p emulator and on the real Mi Box with its stock remote only. Log KeyEvents to confirm which keys the remote actually delivers. Run a short hallway test with the parents (tasks: open the app, change channel, find a news channel, add a favorite, return to the channel list, exit). Check that every screen has an initial focus, no focus traps, and correct Back behavior at each layer.
- Exit confirmation: follow Google (no exit gating). If the family accidentally exits often, add an optional, default-OFF 'Çıkmak için Geri'ye tekrar basın' toast instead of a modal dialog. Sideloaded apps aren't Play-reviewed, but the toast is still the less confusing choice.

## OPEN QUESTIONS
- Exact key set of the user's Xiaomi remote: number keys, CH± keys, INFO/GUIDE or Menu keys? Verify on the device by logging KeyEvents. Does the Google Assistant or mic key ever reach the app?
- Exact Android TV OS version and API level on the user's Mi Box S 2nd Gen (believed to be Android TV 12 / API 31). This sets minSdk and targetSdk and the available accessibility APIs.
- Is now/next (EPG) data legally and reliably available for Turkish national channels? It decides whether the info banner shows program titles and whether an EPG screen is feasible.
- Official stream sources and URLs per channel (TRT/tabii, ATV, Kanal D, Show, Star, NOW, TV8, Kanal 7, news channels) and their stability or geo/HDMI restrictions are out of scope here and need the channel research topic.
- Do the parents prefer chips that filter on focus (TV tab convention, fewer presses) or only on OK (more explicit)? Needs a quick test.
- Does tv-material 1.1.0 ship any Dialog component? None was confirmed; the plan assumes a Compose Dialog with a tv Surface and Buttons.
- Exact tv-material default focus values (Card/Button/ListItem focusedScale, border widths) and default type-scale sp values. Verify in the API reference or source before finalizing Figma specs.
- Current contents and last-updated date of the Figma 'TV Design Kit' (community file 1235253029449067033). Figma returned 403, so I could not confirm Material 3 alignment or the frame size used inside the kit.
- Whether Modifier.focusRestorer is non-experimental in the Compose UI version pulled by BOM 2026.09.00. A secondary source says it became stable in 1.8.0.
- Does the family want an exit guard despite Google's no-exit-gating guidance? If so, use the optional double-Back toast.
- Is a Turkish TalkBack experience needed (any visually impaired family member)? If yes, every card and overlay needs a contentDescription in Turkish.

## VERIFY MISSING
- Sideload policy, 2026–2027: Google's developer verification began enforcement on 30 Sep 2026, but only for phones and tablets in Brazil, Indonesia, Singapore and Thailand. TV is not enforced yet; the global rollout is planned for 2027. ADB installs need no verification and ADB itself is unchanged. A free 'limited distribution' account covers up to 20 devices with no ID and no fee. Once enforcement reaches TV, unregistered apps can be installed or updated only through the 'advanced flow' (24 h wait) or ADB. The 'Güncelleme Mevcut' self-update screen therefore depends on registering the app (limited distribution) or on ADB updates. Surface.setFrameRate exists on API 30, and Media3 offers a video frame-rate change strategy. Test on the box whether display mode switching (TV-FR) works.
